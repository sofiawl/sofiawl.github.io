Did you know

Weight-space programming repairs model behavior without gradient descent by treating network weights as code to be inspected and modified directly. In practice, forward pass activations define a vector direction for repetitive failure loops and a contrasting direction for productive steps. Edits are then constrained to discrete bit-level adjustments, like flipping signs or shifting exponents in BF16 numbers, which directly weaken the undesirable activation trajectories. Because row-wise changes decouple cleanly, the entire intervention solves as independent discrete optimization problems without backpropagation or fine-tuning datasets.
